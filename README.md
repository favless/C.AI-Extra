Build instructions for Charrium

Requirements:

- Node.js 20 or later
- npm

1. Clone/download the source code.
2. Open a terminal in the project directory.
3. Install dependencies:
   npm install
4. Build the extension:
   npm run build

The generated extension is output to `dist/` directory.

The contents of the `dist/` directory are the files submitted to Mozilla Add-ons.
